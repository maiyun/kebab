###### signal?

`AbortSignal`

取消上传请求并销毁输入流，等待已知的未完成分片清理后返回 false
清理使用独立的 30 秒超时信号，失败时记录错误；不传则沿用原上传流程
不删除同名对象，上传完成与取消同时发生时，由调用方清理独立任务文件
